# Marketech Digital Website — Agent Instructions

## Marketech AI Reviewer — mandatory independent gate

The Marketech Digital public website is enrolled in the Marketech OS/Jarvis AI Reviewer system as a **Tier 2** external-facing project.

- Material code, copy/claims, forms/contact handling, analytics/tracking, SEO, dependency, deployment and production-readiness changes require an independent reviewer record.
- The producing agent cannot be the sole reviewer of its own material work.
- Missing reviewer evidence fails closed for production release promotion.
- Reviewer checks must include factual truthfulness of service/client claims, security/privacy of contact and analytics data, accessibility/UX, SEO regressions, dependency risk, broken links/forms and deployment rollback readiness.
- Never fabricate clients, case studies, certifications, guarantees, performance numbers or capabilities.
- Never commit secrets.
- See `.marketech/reviewer.json` and `.marketech/BASELINE_REVIEW.md`.
