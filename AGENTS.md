# Marketech Digital Website — Agent Instructions

## Marketech independent Reviewer — mandatory gate

The Marketech Digital public website is a **Tier-2 external-facing project** enrolled in the central JARVIS / Marketech independent Reviewer fabric.

- Material code, public copy/claims, forms/contact handling, analytics/tracking, SEO, dependency, deployment and production-readiness changes require an independent review record bound to the exact candidate head before consequential promotion.
- The producing agent may prepare evidence and deterministic checks but may not self-approve its own material change.
- Reviewer execution belongs to the central Marketech Reviewer / Trusted runtime. Do not create a duplicate per-repository hosted GitHub Action or repository-local reviewer credential path merely to obtain a badge.
- Missing, quota-rejected, stale-head or infrastructure-only review evidence is not approval. It fails closed for consequential merge/release promotion while safe non-consequential engineering may continue.
- Review must check factual truthfulness of service/client/case-study/metric claims, contact and analytics privacy/security, spam/abuse boundaries, accessibility/responsive UX, SEO regressions, dependency risk, broken links/forms and deployment/rollback readiness.
- Never fabricate clients, case studies, certifications, guarantees, performance numbers or capabilities.
- Never commit secrets.
- A Reviewer verdict alone does not authorize production deployment, provider credentials, paid spend, public outbound communication or any other separately gated consequential action.

See `.marketech/reviewer.json` and `.marketech/BASELINE_REVIEW.md`.
